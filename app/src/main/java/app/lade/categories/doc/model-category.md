# Category

Справочник категорий.


| Поле | Тип | Описание |
|------|-----|----------|
| id | integer, autoincrement | PK |
| key | CategoryKey? | Пресет приложения; у пользовательской — `null` |
| title | string | Имя в UI |
| color | ColorKey | Цвет из набора |
| archivedAt | Instant? | `null` — активна; иначе архив |

При наличии ссылок: из UI — `archivedAt` (мягко); жёсткое удаление только без ссылок.

## CategoryKey

| key | title (RU) | Типичное использование |
|-----|------------|------------------------|
| `sleep` | Сон | ночной / дневной сон |
| `work` | Работа | смена, офис |
| `lunch` | Обед | обеденный перерыв |
| `meal` | Еда | завтрак, ужин, перекусы |
| `commute` | Дорога | поездки |
| `sport` | Спорт | тренировки |
| `run` | Бег | бег |
| `walk` | Ходьба | прогулки |
| `health` | Здоровье | врачи, самочувствие |
| `study` | Учёба | курсы, чтение |
| `home` | Быт | дом, уборка |
| `family` | Семья | семья |
| `leisure` | Отдых | досуг |
| `care` | Уход за собой | гигиена |
| `other` | Прочее | запасной ярлык |

Сиды: по одной Category на каждый key при первом запуске.

## ColorKey

| key | hex | Название (RU) |
|-----|-----|---------------|
| `slate` | `#64748B` | Серо-синий |
| `stone` | `#78716C` | Камень |
| `red` | `#DC2626` | Красный |
| `orange` | `#EA580C` | Оранжевый |
| `amber` | `#D97706` | Янтарный |
| `green` | `#16A34A` | Зелёный |
| `teal` | `#0D9488` | Бирюзовый |
| `sky` | `#0284C7` | Голубой |
| `blue` | `#2563EB` | Синий |
| `violet` | `#7C3AED` | Фиолетовый |
| `pink` | `#DB2777` | Розовый |

Ориентир сидов: `sleep`→`violet`, `work`→`blue`, `lunch`/`meal`→`amber`, `commute`→`stone`, `sport`/`run`/`walk`→`green`, `health`→`teal`, `study`→`sky`, `home`→`orange`, `family`→`pink`, `leisure`→`red`, `care`→`slate`, `other`→`stone`.
