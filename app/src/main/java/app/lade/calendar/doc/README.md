## Стык дня

1. Сутки = локальная дата `[00:00, +1 day)`.
2. Занятость — порты `time` (формулу free не копировать); день читает `TimeBlock`.
3. Due-привычки — порты `habits` + RRULE; без обязательного слота.
4. Статусы отметки — правила `habits` (после UI отметок).
