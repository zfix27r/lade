# Правила `time`

## Positioning

Фича = **управление и анализ занятости суток** (шаблоны → блоки), не «календарь дел».
UI-копирайт: «Занятость», empty-state про ритм суток.

2. `intervals` не пересекаются; каждый `end > start` в пределах суток.
3. Пример: работа `08:00–12:00` и `14:00–18:00` + обед `12:00–14:00`.
4. Развёртка → TimeBlock, `source = schedule`.

## TimeBlock

1. `end > start`; на ядре блок в одних сутках (через полночь — два блока).
2. Пересечения запрещены; busy = сумма длительностей.
3. Разовые: `source = manual`, без `scheduleId`.
4. Импорт не затирает manual/schedule.
5. Шаг UI: 5 минут.

## Свободное время

```
unallocated = 24h − sum(duration(TimeBlock on date))
```

Сумма блоков ≤ 24h.

## DayPlan (опционально)

Бюджет долей по категориям ≤ 24h. Не заменяет расчёт free по блокам.

## Редактор блоков

create / update / delete / move / split — с валидацией пересечений и 24h.
