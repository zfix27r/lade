# Правила `habits` (день)

1. Строка History появляется при отметке / явном добавлении / политике missed.
2. При создании слепок копируется из Habit; дальше History и Habit независимы.
3. День без History, но Habit due → статус `planned` (из RRULE). Блок занятости не создаётся.
4. Аналитика прошлого — только History.
5. `done` не создаёт блок занятости автоматически.
6. Опциональная связь с блоком занятости — только явное действие пользователя.

## Статус за день

| Ситуация | Статус |
|----------|--------|
| History.result = `done` | done |
| History.result = `skipped` | skipped |
| Нет отметки, день due ещё идёт | planned |
| Нет отметки, день due прошёл | missed |
