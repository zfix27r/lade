## Стык дня

1. Сутки = локальная дата `[00:00, +1 day)`.
2. День/неделя/месяц/лента читают **Entry + EntryHistory** (`EntryDayProjector`); schedule — проекция без History.
3. Одиночная Entry маскирует пересекающуюся серию; порядок слоёв — `KindPriority`.
4. Отметки привычек — `MarkEntryDay` → EntryHistory (без портов habits/time в calendar VM).
