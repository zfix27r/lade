# Философия архитектурных правил

1. **Правила — не для того, чтобы поймать злоумышленника. А для того, чтобы не дать уставшему разработчику или перегруженному ИИ случайно свернуть не туда.**

2. **Правила живут в коде.** Каждое правило — это отдельный проверяющий файл. Из этих файлов автоматически генерируется человеческая документация (.md). Это гарантирует, что документация никогда не устаревает, а код правил всегда является единственным источником истины.
