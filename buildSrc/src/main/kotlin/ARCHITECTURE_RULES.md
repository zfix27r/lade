# Архитектурные правила ArchGuard

## Общие правила

| ID | Правило | Описание |
|---|---|---|
| `scenario_is_object` | Сценарий — это `object` | Сценарий должен быть объявлен как `object`, а не `class`. |
| `scenario_methods_named` | Именованные шаги | Публичные методы должны называться `step1`, `step2`, ... `step6`, `stepResult`. |
| `stepResult_exists` | Обязательный финал | Метод `stepResult` является обязательным. |
| `scenario_methods_one_param` | Один параметр | Каждый публичный метод принимает ровно **1** параметр. |
| `scenario_methods_return_unit` | Возврат `Unit` | Все публичные методы возвращают `Unit`. |
| `scenario_methods_one_line` | Одна строка | Тело публичного метода должно содержать **ровно одну** строку кода (вызов приватного метода). |
| `scenario_models_exist` | Модели рядом | Для каждого публичного метода (`stepX`) должен существовать файл модели `StepXModel.kt` в той же папке. |
| `scenario_max_methods` | Не более 7 шагов | Общее количество публичных методов (`step1`...`stepResult`) не должно превышать 7. |

## Применение

- Правила применяются к файлам в папках `app/domain/scenarios/**` и `feature/*/domain/scenarios/**`.
- Нарушение любого правила приводит к ошибке сборки проекта.
